# UniPath — Student Course Guidance System

## 📋 Project Overview

UniPath is a web-based course recommendation prototype developed by a team of four Software Engineering students at Manchester Metropolitan University.

The project aims to help prospective university students explore suitable degree programmes based on their interests, academic strengths and career aspirations.

## 🎯 Key Features

- **Interactive Questionnaire:** Collects students' academic interests, strengths, learning preferences and career goals.
- **Course Matching:** Uses simplified keyword-based matching and simulated scoring to evaluate potential course recommendations.
- **Personalised Results:** Displays up to three recommended courses based on questionnaire responses.
- **Database Design:** MySQL database structures for managing student information, questionnaire responses, courses and recommendations.
- **Backend API:** Node.js and Express.js endpoints for accessing course information and working with student responses.

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Version Control:** Git and GitHub

## 🚀 Running the Project

1. Clone or download the repository.
2. Install Node.js and MySQL.
3. Run the SQL script in `database_schema.sql` to create the database.
4. Configure the local database connection in `server.js`.
5. Run `npm install` followed by `npm start`.
6. Open `http://localhost:3000` in your browser.

*The project requires local database configuration. The setup instructions should be verified against your environment.*

## 📌 Project Scope

UniPath was developed and demonstrated as a first-year academic prototype rather than a production-ready application.

The recommendation functionality includes simplified matching and simulated scores. The frontend questionnaire uses browser storage, while the backend provides separate database functionality.

The project was not publicly deployed.
